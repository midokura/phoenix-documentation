# ベアメタル管理

ベアメタルサーバーのプロビジョニングと管理

このガイドでは、Console UI でベアメタルサーバーをプロビジョニング・管理する方法を説明します。ベアメタルでは、ハイパーバイザーのオーバーヘッドなしに物理サーバーへ直接かつ専有的にアクセスできます。

:::note

ベアメタルサーバーをプロビジョニングする前に、オペレーターが物理ノードを登録し、ハードウェアインスペクションを完了しておく必要があります。オペレーターガイドの [ベアメタルノードの登録](../service-operator/INSTALL_BAREMETAL_NODE.md) を参照してください。ノードはプロビジョニング可能になる前に `available` 状態である必要があります。

:::

---

## ベアメタルサーバーのプロビジョニング

ノードが `available` 状態になったら、OS イメージをデプロイしてプロビジョニングします。プロビジョニングには通常 15〜30 分かかります。

1. **Servers** サイドバーで **create server** をクリックします。
2. サーバータイプとして **Bare Metal** を選択します。
3. フォームに入力します:

   | フィールド | 説明 |
   |---|---|
   | **Server Name** | プロビジョニングされるサーバーインスタンスの名前。 |
   | **Flavor** | 物理ノードの仕様に合致するハードウェアプロファイル。 |
   | **Image** | デプロイする OS イメージ。 |
   | **User Script** | 初回起動後に実行されるオプションのシェルスクリプト（cloud-init）。 |

4. **Provision Server** をクリックします。

プロビジョニング中、サーバーは **Servers** パネルに表示されます。

:::note

登録済みの SSH 鍵はプロビジョニングされた OS へ自動的に注入されるため、サーバーがアクティブになり次第 SSH で接続できます。

:::

---

## ベアメタルサーバーへの接続

**Servers** パネル上でサーバーのステータスが **ACTIVE** になったら、テーブルに表示されている IP アドレスを使って接続します。

```bash
ssh ubuntu@<server-ip-address>
```

ユーザー名は使用する OS イメージによって異なる場合があります。

:::note

ベアメタルサーバーへはテナント VPN ネットワークからのみアクセスできます。セットアップ方法は [VPN 設定](./VPN_CONFIGURATION) を参照してください。

:::

---

## ベアメタルサーバーの削除

削除するとサーバーがデプロビジョニングされ、物理ノードがプールに戻されます。

1. **Servers** パネルでサーバーを見つけます。
2. 行の **削除アイコン** をクリックします。
3. 削除を確定します。

物理ノードの登録自体を完全に削除するには、サーバーがデプロビジョニングされた後に **Baremetal** パネルからノードを削除します。

:::note

サーバーがデプロイされている間はノードを削除できません。先にサーバーを削除してから、ノードを削除してください。

:::
