# ベアメタル管理

ベアメタルサーバーのプロビジョニングと管理

本ガイドでは、Console UIを使用してベアメタルサーバーをプロビジョニングおよび管理する方法を説明します。ベアメタルでは、ハイパーバイザーを介さずに物理サーバーを専有して利用できます。

:::note

ベアメタルサーバーをプロビジョニングする前に、オペレーターが物理ノードを登録し、ハードウェアインスペクションを完了しておく必要があります。詳細については、オペレーターガイドの [ベアメタルノードの登録](../service-operator/INSTALL_BAREMETAL_NODE.md) を参照してください。プロビジョニングを開始するには、ノードが `available` 状態である必要があります。

:::

---

## ベアメタルサーバーのプロビジョニング

ノードが `available` 状態になったら、OS イメージをデプロイしてプロビジョニングします。プロビジョニングには通常 15〜30 分かかります。

1. **Servers** サイドバーで **create server** をクリックします。
2. サーバータイプで **Bare Metal** を選択します。
3. 以下のフォームを入力します。

   | フィールド | 説明 |
   |---|---|
   | **Server Name** | プロビジョニングするサーバーインスタンスの名前。|
   | **Flavor** | 物理ノードの仕様に対応するハードウェアプロファイル。 |
   | **Image** | デプロイする OS イメージ。 |
   | **User Script** | 初回起動後に実行されるオプションのシェルスクリプト（cloud-init）。 |

4. **Provision Server** をクリックします。

プロビジョニング中のサーバーは、**Servers** パネルに表示されます。

:::note

登録済みのSSH鍵はプロビジョニングしたOSに自動的に追加されるため、サーバーがアクティブになるとSSHで接続できます。

:::

---

## ベアメタルサーバーへの接続

**Servers** パネルでサーバーのステータスが **ACTIVE** になったら、テーブルに表示されているIPアドレスを使用して接続します。

```bash
ssh ubuntu@<server-ip-address>
```

ユーザー名は使用する OS イメージによって異なる場合があります。

:::note

ベアメタルサーバーには、テナントVPNネットワークからのみアクセスできます。セットアップ方法については、 [VPN 設定](./VPN_CONFIGURATION) を参照してください。

:::

---

## ベアメタルサーバーの削除

サーバーを削除するとデプロビジョニングが実行され、物理ノードがプールに戻ります。
1. **Servers** パネルでサーバーを見つけます。
2. 行にある **削除アイコン** をクリックします。
3. 削除を確定します。

物理ノードの登録を完全に削除するには、サーバーをデプロビジョニングした後、 **Baremetal** パネルからノードを削除します。

:::note

サーバーのデプロイ中はノードを削除できません。サーバーを削除してから、ノードを削除してください。

:::
